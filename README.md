# ☕ 카르네(Carne) - 원두 정기구독 서비스

> **"매일 특별한 커피 타임, 고객님의 취향에 맞게 스페셜 커피를 즐겨 보세요."**
> 
> 카르네(Carne)는 사용자 맞춤형 스페셜티 커피 원두를 정기적으로 배송해 드리는 웹 서비스의 프론트엔드 랜딩 페이지입니다. 사용자는 자신의 취향에 맞는 원두 로스팅 단계를 선택하고, 다양한 커피 타입을 추천받을 수 있습니다.

## 📌 주요 기능 (Key Features)

* **뉴스레터 구독 시스템:** 이메일 입력을 통한 신규 소식 및 구독 안내문 발송 폼 제공
* **맞춤형 로스팅 선택:** 라이트, 미디엄, 다크 등 취향에 따른 원두 로스팅 단계 선택 기능
* **타입별 커피 가이드:** 너티드(Nutty), 비비드(Vivid), 다크(Dark) 등 직관적인 카드형 UI를 통한 커피 취향 가이드 제공
* **아코디언 FAQ:** 라디오 버튼(`input type="radio"`)을 활용하여 CSS만으로 부드럽게 동작하는 사용자 친화적 FAQ 섹션 구현
* **멤버십 혜택 안내:** 온라인몰 할인 및 상품권 증정 등 회원 전환을 유도하는 직관적인 정보 제공

<br/>
